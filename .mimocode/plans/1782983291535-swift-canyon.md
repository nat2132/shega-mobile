# Flat UI Redesign Plan — Shega Mobile

## Overview

Transform the entire app from its current "Liquid Glass" frosted-glass aesthetic to a clean, modern Flat UI. This means replacing semi-transparent rgba overlays, BlurView effects, specular highlights, depth shadows, and gradient fills with solid colors, clean borders, and minimal shadows.

---

## Phase 1: Core Design Token System (Foundation)

All UI changes flow from the token system. Fix this first and everything downstream inherits the new look.

### 1A. Rewrite `createGlassTokens.ts` → Solid Flat Tokens

**File:** `src/utils/createGlassTokens.ts`

Replace all glass/blur/rgba tokens with solid flat equivalents. The token shape stays the same so consumers don't break — only the values change.

**Current → New mapping:**
| Token | Current (glass) | New (flat) |
|---|---|---|
| `bg` | `colors.background` | Same (unchanged) |
| `bgCard` | `rgba(255,255,255,0.06)` | `colors.card` (solid) |
| `bgCardHover` | `rgba(255,255,255,0.09)` | Slightly lighter/darker variant of `colors.card` |
| `bgCardStrong` | `rgba(255,255,255,0.10)` | `colors.surface` |
| `border` | `rgba(255,255,255,0.08)` | `colors.border` (solid) |
| `borderLight` | `rgba(255,255,255,0.15)` | Lighter solid border |
| `borderAccent` | `rgba(255,255,255,0.22)` | `colors.tint` with 20% opacity |
| `fg` | `colors.text` | Same |
| `fgSecondary` | `colors.textSecondary` | Same |
| `muted` | `colors.textSecondary` | Same |
| `mutedLight` | `rgba(255,255,255,0.30)` | `colors.textSecondary` with 15% opacity |
| `glow` / `glowStrong` | rgba overlays | Remove or set to transparent |
| `accentGlass` / `accentGlassStrong` | rgba accent tint | Solid accent with low opacity |
| `reflection` | rgba overlay | Transparent |
| `gradientStart` / `gradientEnd` | rgba gradients | Solid color or transparent |
| `surface` | `rgba(255,255,255,0.06)` | `colors.surface` |
| `shadowColor` / `shadowOuter` / `shadowInner` | Deep shadows | Minimal: `shadowColor: '#000'`, `shadowOuter: 0.06` (light) / `0.15` (dark) |
| `borderSubtle` / `borderGlass` / `borderGlassStrong` | Glass borders | Solid subtle borders from `colors.border` |
| `glassTint` / `glassTintStrong` | Translucent accent tints | Solid accent at low opacity |
| `specularPeak` / `highlight` / `highlightStrong` | Specular highlights | Transparent (removed) |
| `ambientGlow` / `depthShadow` / `refractEdge` | 3D effects | Transparent (removed) |
| `rimTop/Bottom/Left/Right` | Edge lighting | Transparent (removed) |
| `surfaceFill` / `surfaceFillStrong` | Translucent fills | `colors.surface` |
| `blurTint` | 'light'/'dark' | Keep for compat but unused |

**Chart tokens** stay mostly the same (already clean).
**Input tokens** stay mostly the same but use solid backgrounds.

### 1B. Enhance Theme Colors

**File:** `src/constants/theme.ts`

Add new tokens needed for flat design:
- `surfaceVariant` — slightly different from surface, for alternating rows/sections
- `borderLight` — lighter border for subtle separators
- `overlay` — solid overlay color for modals

Refine each of the 7 themes to ensure good contrast ratios with the new flat approach.

### 1C. Simplify Per-Screen Glass Files

**Files:** All 16 `glass-*.ts` files in `src/screens/*/`

These become thin wrappers. Remove screen-specific glass tokens (glassCard, glassStrong, glassBorder, etc.). Each file keeps its spring/timing animation constants and layout dimensions but the token generation now calls the simplified `createGlassTokens`.

### 2A. `AppCard.tsx`

- Use solid `colors.card` background, `colors.border` for border

### 2D. `AppListItem.tsx`

## Phase 3: Navigation Components

### 3A. `CustomTabBar.tsx`

**Current:** BlurView background, translucent pill, glass effect
**New:**
- Replace `BlurView` with solid `colors.tabBar` background
- Solid pill indicator with `colors.tint` at 10-15% opacity
- Remove shadow from wrapper
- Clean 1px top border instead of shadow
- Solid background color from theme

### 3B. `GlobalHeader.tsx`

**Current:** BlurView, rounded pill shape, shadows, translucent background
**New:**
- Replace `BlurView` with solid background (`colors.header` or `colors.background`)
- Remove `borderRadius: 35` (pill shape) → standard rectangular header
- Remove all shadows
- Solid border-bottom instead of shadow

- Replace iOS `BlurView` with solid `rgba(0,0,0,0.55)` overlay on both platforms

### 3D. `sidebar.tsx`

**Current:** Glow nodes (decorative rgba circles), glass tokens
**New:**
- Remove glow node decorative elements (the 3 absolute-positioned circles)
- Solid background color
- Clean dividers between menu sections
- Keep all navigation logic and routes unchanged

## Execution Strategy

Given the ~185 files and massive scope, execute in this order:

1. **Phase 1** (token system) — single commit, foundation for everything
2. **Phase 2** (core components) — small batch, high impact
3. **Phase 3** (navigation) — small batch, high visibility
4. **Phase 4-5** (dialogs/sheets/modals) — medium batch
5. **Phase 6A** (dashboard) — largest screen, most visible
6. **Phase 6B-6H** (remaining screens) — parallelize where possible
7. **Phase 7-9** (charts, animation, utilities) — cleanup pass

Each phase can be verified independently by running the app.

---

## Verification

After each phase:
1. Run `npx expo start` and test on both iOS simulator and Android emulator
2. Toggle through all 7 themes (Light, Dark, Midnight, Emerald, Charcoal, Slate, Cocoa)
3. Verify no BlurView crashes on Android
4. Check that all business logic (database queries, navigation, modals) still works
5. Verify no glass/blur artifacts remain visually
6. Check accessibility contrast in each theme
